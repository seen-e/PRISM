# Bundled StarVLA

This directory contains the complete StarVLA source snapshot used by the
PRISM release, with PRISM integrated directly into the data loader and action
head. Do not clone a separate StarVLA checkout or apply patches.

Installation, training, and serving instructions are in the repository-level
[`README.md`](../README.md). Source provenance is recorded in
[`SOURCE_VERSIONS.md`](../SOURCE_VERSIONS.md).
